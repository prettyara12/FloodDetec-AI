1. Dataset & Pelatihan Model (Kaggle)

Model dilatih menggunakan dataset Kaggle Flood Area Segmentation dengan bobot biner tersimpan dalam berkas model_training.h5 (122.6 MB). Bobot kemudian dikonversi menjadi representasi ONNX teroptimasi untuk inferensi CPU yang sangat efisien.

Dimensi Input Citra 256 × 256 × 3 (RGB)
Format Output Masker 256 × 256 × 1 (Probabilitas)

Fungsi Aktivasi Terakhir Sigmoid [0, 1]
Optimizer Pelatihan Adam (lr=0.001, β1=0.9, β2=0.999)
Fungsi Loss Binary Crossentropy

2. Arsitektur Jaringan Attention U-Net

Attention U-Net merupakan penyempurnaan dari arsitektur U-Net standar. Pada U-Net konvensional, seluruh informasi dari encoder dilewatkan langsung ke decoder melalui skip connection, yang kerap membawa noise latar belakang (vegetasi, atap rumah, bayangan). Attention U-Net menambahkan Attention Gates yang memfilter fitur encoder secara adaptif sebelum digabungkan.

Formulasi Matematis Attention Gate

Koefisien atensi $\alpha \in [0, 1]$ dihitung dari kombinasi linear fitur spasial encoder ($x_l$) dan sinyal gating decoder ($g$):

ψ = σ1( W_x × x_l + W_g × g + b_g )
α = σ2( W_ψ × ψ + b_ψ )
x_filtered = α ⊙ x_l

Di mana $\sigma_1$ adalah aktivasi ReLU, $\sigma_2$ adalah fungsi Sigmoid untuk menghasilkan bobot atensi bernilai 0 hingga 1, dan $\odot$ adalah operasi perkalian per elemen (*element-wise multiplication*).

Encoder (4 Tahap)
  • Tahap 1: 32 filter • 2× Conv2D (3×3) + ReLU + MaxPool (2×2)
  • Tahap 2: 64 filter • 2× Conv2D (3×3) + ReLU + MaxPool (2×2)
  • Tahap 3: 128 filter • 2× Conv2D (3×3) + ReLU + MaxPool (2×2)
  • Tahap 4: 256 filter • 2× Conv2D (3×3) + ReLU + MaxPool (2×2)
Bottleneck

512 filter • 2× Conv2D (3×3, padding='same') + Batch Normalization + ReLU. Mengompresi representasi semantik global terdalam pada resolusi 16×16 piksel.

Decoder & Attention Gates (4 Tahap)
  • Tahap 4: Attention Gate (256) + Upsampling (2×) + Concat + 2× Conv2D
  • Tahap 3: Attention Gate (128) + Upsampling (2×) + Concat + 2× Conv2D
  • Tahap 2: Attention Gate (64) + Upsampling (2×) + Concat + 2× Conv2D
  • Tahap 1: Attention Gate (32) + Upsampling (2×) + Concat + 2× Conv2D

3. Matriks Klasifikasi Bahaya Banjir

Berdasarkan rekomendasi mitigasi bencana geospasial, luas genangan air dikategorikan menjadi 4 tingkatan keparahan:

Status Ambang Persentase Warna Indikator Kondisi Geospasial Tindakan Mitigasi
Aman < 5.0% Hijau Emerald (#10B981) Kondisi air normal, mengalir dalam saluran primer/sungai. Monitoring rutin pintu air dan saluran drainase.
Waspada 5.0% – 20.0% Biru Kobalt (#3B82F6) Genangan air melimpas ke bantaran sungai atau lahan rendah. Siapkan pompa bergerak dan beri peringatan ke warga sekitar bantaran.
Siaga 20.0% – 50.0% Oranye Amber (#F59E0B) Air menggenangi kawasan pemukiman padat dan jalan utama. Aktivasi jalur evakuasi, siagakan perahu karet, dan amankan instalasi listrik.
Awas > 50.0% Merah Crimson (#EF4444) Banjir bandang/luapan masif menenggelamkan sebagian besar kawasan. Evakuasi darurat total, dirikan posko pengungsian dan dapur umum.

4. Spesifikasi REST API

Sistem menyediakan antarmuka REST API berbasis FastAPI yang dapat diintegrasikan dengan aplikasi webGIS, sistem informasi geospasial (SIG), atau dashboard kebencanaan lainnya:

POST /api/segment

Mengunggah foto banjir baru untuk dieksekusi oleh model Attention U-Net.

Parameter Form-Data:
  • file (UploadFile, Wajib): Berkas citra JPG atau PNG (maks 10 MB).
  • threshold (float, Opsional): Ambang batas probabilitas biner (default 0.50, range 0.05 s.d. 0.95).
POST /api/recalculate

Menyesuaikan ambang batas threshold pada citra yang sedang aktif tanpa melakukan inferensi ulang.

Payload JSON: {"threshold": 0.65}
GET /api/samples

Mengambil daftar citra sampel uji bawaan sistem beserta metadata perkiraan risiko banjir.

GET /api/health

Memeriksa status kesiapan model Attention U-Net dan spesifikasi engine ONNX Runtime.
